# Morning Brief Routines

Automated daily morning briefings generated by Claude Code on a schedule.

Each run pulls from:
- **Google Calendar** — upcoming events and schedule
- **Gmail** — unread emails sorted by urgency
- **Web Search** — news on topics of interest (Elon/SpaceX, F1, tech/markets)
- **ntfy.sh** — push notification to `dakota-notifications-cluade`

## Structure

```
briefs/
  YYYY-MM-DD.md   # Daily briefing archive
```

## Setup

This routine runs on a Claude Code scheduled session. The notification channel is `ntfy.sh/dakota-notifications-cluade`.
